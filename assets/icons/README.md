# Runtime interface icons

Replace these SVGs to customize Pixloom's controls. Keep filenames and use paths
inside a 24 x 24 viewBox. White glyphs are tinted by the UI; header strokes are
1.2px. Valid edits reload in the running source-checkout app within roughly 500ms.
Builds copy this directory's SVGs into `icons/` beside the executables. Ship that
folder with the desktop. See `docs/icons.md` for the file-to-control map.
