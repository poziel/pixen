# Guidance provenance

The imported agents, workflow skills and numbered rules originate from
[Aseprite AI Artist](https://github.com/with-pebbly/aseprite-ai-artist), by
**with-pebbly**, copyright (c) 2026. Its [MIT license](LICENSE) is retained here.
The existing `skills/pixen` and `skills/pixel-art` bundles keep their own sources.

The imported guidance has been renamed for Pixen: editor references, `pixen:*`
workflow names and `.pixen` working-source filenames. Upstream procedures, tool
examples, artistic guidance, agents and pixel templates remain in place.
This terminology pass does not translate the upstream commands to Pixen's MCP
API or register skills, rules, prompts or agents with a client.

References to the actual `.aseprite` interchange format, its conversion behavior
and original source citations retain their real names. The gallery workflow
uses explicit destination placeholders rather than inventing a Pixen gallery or
publishing to the upstream repository.
