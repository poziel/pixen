# Artwork export implementation plan

Goal: File → Export with image, animation, sprite sheet, video and editable .pixen.json outputs.
Architecture: Capture the authoring document under the session lock, then encode and atomically install outside the lock. Reuse core encoders; scale flattened frames with nearest-neighbor sampling.

- [x] Add bounded render transformations and tests for scale/grid ordering and validation.
- [x] Add a native export command with document identity, cancellation, extension and source protection.
- [x] Add an export dialog, File menu command and shortcut; validate format-specific settings.
- [x] Replace executable .pixloom.json naming with .pixen.json and verify frontend/native builds.
